Part 2: Static Baseline

Create a clear static scatterplot of GDP per capita and life expectancy.

#|label: static-plot

static_scatterplot <- ggplot(
  gapminder_2007,
  aes(
    x = gdp_per_capita,
    y = life_expectancy,
    color = continent
  )
) +
  geom_point(
    size = 2.5, 
    alpha = 0.8
    ) +
  scale_x_log10(
    labels = scales::label_dollar()
  ) +
  scale_color_viridis_d() +
  labs(
    title = "Life Expectancy Generally Increased with GDP per Capita",
    subtitle = "Country-level observations from 2007",
    x = "GDP per capita (log scale)",
    y = "Life expectancy in years",
    color = "Continent",
    caption = "Source: Gapminder"
  ) +
  theme_minimal(
    base_size = 13
  )

Part 3: Custom Tooltip

Add tooltip text containing country, continent, life expectancy, GDP per capita, and population.

interactive_scatterplot <- ggplot(
  gapminder_2007,

Part 5: Interactive Trend

Calculate continent-level mean life expectancy over time and create an interactive line graph with unified hover.

#|label: trend-summary

continent_trends <- gapminder_data %>%
  group_by(
    continent,
    year
  ) %>%
  summarize(
    mean_life_expectancy = mean(
      life_expectancy,
      na.rm = TRUE
    ),
    .groups = "drop"
  )

Build Interactive Trend Graph

#|label: trend-graph

interactive_trend <- ggplot(
  continent_trends,
  aes(
    x = year,
    y = mean_life_expectancy,
    color = continent,
    text = paste0(
      "<b>",
      continent,
      "</b>",
      "<br>Year: ",
      year,
      "<br>Mean life expectancy: ",
      round(
        mean_life_expectancy,
        digits = 1
      ),
      " years"
    )
  )
) +
  geom_line(
    linewidth = 1
  ) +
  geom_point(
    size = 1.8
  ) +
  scale_color_viridis_d() +
  labs(
    title = "Mean Life Expectancy Increased Across Continents",
    subtitle = "Hover over a point or zoom into time period",
    x = "Year",
    y = "Mean life expectancy in years",
    color = "Continent"
  ) +
  theme_minimal(
    base_size = 13
  )

Convert Trend Graph to Interactive Plotly

#|label: interactive-trend

ggplotly(
  interactive_trend,
  tooltip = "text",
  dynamicTicks = TRUE
) %>%
  style(
    hoverinfo = "skip",
    traces = c(1, 3, 5, 7, 9)
  ) %>%
  layout(
    hovermode = "x unified"
  ) %>%
  config(
    displaylogo = FALSE,
    responsive = TRUE
  )

Part 6: Interactive Table

Create a searchable DT table with formatted values.

#|label: interactive-table

table_data <- gapminder_2007 %>%
  transmute(
    Country = country,
    Continent = continent,
    `Life expectancy` = round(
      life_expectancy,
      digits = 1
    ),
    `GDP per capita` = round(
      gdp_per_capita
    ),
    Population = population
  )

datatable(
  table_data,
  rownames = FALSE,
  filter = "top",
  options = list(
    pageLength = 10,
    autoWidth = TRUE
  ),
  caption = htmltools::tags$caption(
    style = "caption-side: top; text-align: left;",
    "Country-level indicators in 2007"
  )
) %>%
  formatCurrency(
    columns = "GDP per capita",
    currency = "$",
    digits = 0
  ) %>%
  formatRound(
    columns = "Life expectancy",
    digits = 1
  ) %>%
  formatRound(
    columns = "Population",
    digits = 0
  )

Part 8: Evaluate Interactivity

Explain which interaction supports which user question and whether the added complexity is justified.

The interactive Plotly visualization and DT table provide different methods for accessing related Gapminder data. More specifically, the Plotly scatterplot allows viewers to hover over and zoom into plotted points that represent individual country-level observations detailing GDP per capita, life expectancy, and population size. Furthermore, the interactive trend graph allows for similar interactions while assessing changes in mean life expectancy over time by continent. In contrast, the DT table provides search and filtering functions that allow users to locate individual country data. The added complexity of these interactive methods is justified because the features support more detailed data exploration. They also make comparisons easier to interpret than static visualizations alone. The static version of the scatterplot remains useful for users who may be unfamiliar with interactive visualizations or experience difficulties navigating them.
